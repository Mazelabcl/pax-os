## RESUMEN ESTADISTICO

| Metrica | Valor |
|---------|-------|
| Imagenes planificadas (slots de 3 seg) | **120** |
| Imagenes unicas estimadas (descontando reuso) | **~95** |
| Imagenes de personaje (necesitan edit_image con char sheet) | **~42** (Jiggy: 38, siluetas Pax genericas: 4) |
| Imagenes de ambiente Uray Pacha (generate_image) | **~33** |
| Imagenes mundo real (generate_image) | **~16** |
| Imagenes abstractas / texto / diagramas | **~8** |
| Imagenes de transicion / split | **~6** |

### Notas de produccion

1. **Jiggy es el unico personaje con rostro definido.** Todas las demas figuras Pax son siluetas o planos generales. Esto reduce la carga de edit_image drasticamente vs. el script v1.
2. **Las imagenes de mundo real son genericas** — manos en escritorio, persona caminando, cafeteria. No necesitan char sheets. Puras generate_image.
3. **Bloques reutilizables:** la camara de Jiggy (limpia) se usa en ~15 slots con variaciones de luz/expresion. Una sola imagen base con edits de iluminacion cubre la mayoria.
4. **La transicion Pax ↔ mundo real** ocurre en cada ley como puente visual. Mantener consistencia de encuadre: cuando el narrador pasa de Jiggy al espectador, el angulo de camara se mantiene.
