# Resumen narrativo

Macro extremo de una gema rosada (cristal Pax) → pull back lento que revela tunel → Jiggy entra y toma la gema → CUT abrupto a drone chase cam siguiendo a Jiggy corriendo energico por cuevas Pax con cristales pasando rapido en foreground.

**3 sub-shots dentro de un solo prompt Seedance** usando `lens switch to` para los primeros 2 y `abrupt cut to` para el tercero (transicion duro intencional).

**Paleta**:
- 0-5s: rose-magenta profundo + black void (macro gem). Foco unico, dramatico.
- 5-7s: jade-amber tunnel light + magenta accents (tunnel reveal con Jiggy).
- 7-15s: high-energy mixed jade-magenta-amber con cristales rosados pasando rapido en foreground (chase).

**Visual rhythm**:
- Hook (0-1s): macro detalle absoluto. Stop the scroll.
- Build (1-5s): pull back lento, sensacion de revelacion progresiva.
- Impact (5s): CUT duro + entrada Jiggy. Momento "drop".
- Energy (5-15s): fast chase con visual beats cada 0.5-1s (cristales pasando, parallax fuerte).

**Loop seam**: ultimo frame Jiggy desaparece tras una columna de cristal magenta que llena el frame → fade hacia black con punto magenta brillante centrado que matchea con el primer frame (macro gem).
