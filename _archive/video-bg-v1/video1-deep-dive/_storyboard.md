# Resumen narrativo

Cae la camara desde la superficie terrestre humana moderna hacia el mundo subterraneo Pax. Una sola toma continua. Sin personajes hasta el final, donde un grupo Pax aparece como silueta-reveal lejana.

**Paleta evolutiva (15s)**:
- 0-2s: cyan-azul atmosferico (superficie, cielo, aire).
- 2-4s: verde-tierra (corteza, raices, tierra humeda).
- 4-7s: ocre-ambar (capas geologicas, piedras calidas).
- 7-10s: violeta-rosa con chispas magenta (vetas de cristal magico).
- 10-15s: jade + ambar dorado + bioluminiscencia rosa (mundo Pax revelado).

**Visual rhythm**: groove sostenido. Cambios de paleta cada 3s actuan como "bar changes" sin cortes duros. Motion blur lateral por el descenso.

**Loop seam**: ultimo frame es un wide del mundo Pax. Para crossfade limpio en post, el primer frame inicial tiene una particula brillante que matchea con una particula del frame 15.

# Notas para Phase 2 (image gen + Seedance gen)

- **17 frames totales** (0 + 1-15 + 16). Frame 16 es deliberadamente similar a Frame 15 — funciona como master hero key-art para landing y como punto de loop.
- **Variantes 16:9 vs 9:16**: en frames con composicion radial (1, 2, 4, 11) el mismo prompt sirve sin cambio. En frames panoramicos (9, 10, 14, 15, 16) la composicion debe ajustarse — incluido en el prompt como "16:9 X; 9:16 Y" para que el script Python genere las 2 variantes.
- **Continuidad de paleta** justificada narrativamente: descent geologico explica el shift cyan → verde → ocre → magenta-rosa → jade-amber. No es arbitrario.
- **Sin personaje detallado hasta frame 13-15** — reveal narrativo controlado. El hint humano viene tarde, lo cual sostiene el HOOK durante 12s.
- **Loop seam estrategia**: particula brillante del frame 16/0 cierra el ciclo. Implementar crossfade 8-15 frames en post.
